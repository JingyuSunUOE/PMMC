# PMMC v0.2.0

This release runs full-development exploration on Kubernetes. It does not grant independent confirmation, open paper-test, authorize provider spending or establish a performance improvement.

- One controller handles ordinary Kubernetes and optional batch queues. PostgreSQL and MinIO retain distinct PVCs. A shared workload volume can be multi-node RWX or explicitly node-bound RWO. Runtime capacity is measured for the actual model, device and topology rather than assuming eight H100s.
- Select one or more built-in datasets, Answer backbones, methods and components. Scope changes are bound to immutable native jobs, selection, scoring and cost. An independent baseline does not need the PMMC compiler or sibling baselines. A source-backed analysis names its missing inputs instead of silently dispatching model calls.
- Public benchmark locks bind the authors' data and scoring assets to precise revisions. First use prepares only the selected datasets and HF dependencies. The original development/paper boundary is verified by membership, not counts alone. W/R and the scientific thresholds are unchanged.
- A frozen plan shares one ledger across its paid stages and variants. Approval can be finite or explicitly uncapped; reservations, unknown outcomes and rate limits remain enforced. Existing finite approvals are not converted to uncapped.
- Code and image distribution are separate from private deployment. The release source is reproducibly archived from public Git blobs. The separate image lock binds application/IAM images to source identity. The private transfer tool creates one age-encrypted file locally for manual upload, never a published deployment secret.

Follow the [README](README.md) and [Kubernetes guide](docs/release-deploy.md) for first use. The v0.1.0 tag remains available for its original deployment and evidence contracts. A v0.1 controller state or deployment is not an in-place upgrade path. Start v0.2 in its own instance, with fresh service state unless an independently validated migration is explicitly intended. Data, credentials, old approvals and historical experiment results are not release assets.
